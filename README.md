# timegap

[![test](https://github.com/s25c1048zk-source/robosys2026/actions/workflows/test.yml/badge.svg)](https://github.com/s25c1048zk-source/robosys2026/actions/workflows/test.yml)

標準入力から時刻を1行ずつ読み取り、直前の時刻との差を秒単位で出力するコマンドです。
同じ日の作業記録や実験記録について、記録間の経過時間を確認できます。

時刻は HH:MM:SS 形式で入力します。
最初の時刻には比較対象がないため、2行目から計算結果を出力します。
日付をまたぐ記録には対応していません。

## 導入方法

Python 3とGitが使用できる環境で、以下を実行してください。
すでにrobosys2026フォルダーがある場合は、別の場所で実行してください。

```bash
$ git clone https://github.com/s25c1048zk-source/robosys2026.git
$ cd robosys2026
$ chmod +x timegap
```

行頭の `$` はプロンプトを表します。入力する必要はありません。

## 使い方

標準入力から、1行につき1つの時刻を渡します。

```bash
$ printf '12:00:00\n12:00:03\n12:00:10\n12:01:00\n' | ./timegap
3
7
50
```

出力は、それぞれ直前の時刻からの経過秒数です。

時刻を記録したファイルを使う場合は、次のように実行します。

```bash
$ ./timegap < times.txt
```

times.txtの内容の例：

```text
12:00:00
12:00:03
12:00:10
12:01:00
```

## テスト方法

リポジトリのトップディレクトリで実行します。

```bash

```

すべてのテストに成功すると `OK` を表示し、終了ステータス0で終了します。

## 入力条件・エラー時の動作

- 時刻は半角数字で HH:MM:SS 形式にします。
- 時は00～23、分と秒は00～59の範囲です。
- 空行や、時刻の前後に空白がある入力はエラーになります。
- 同じ時刻が続く場合は0を出力します。
- 入力が0行または1行の場合は、何も出力せず正常終了します。
- 最終行に改行がなくても処理できます。
- 時刻の逆戻りはエラーになります。日付をまたぐ記録には対応していません。
- 引数・オプションは受け付けません。

正常終了時の終了ステータスは0、入力や引数のエラー時は1です。
エラーの理由と行番号は標準エラー出力に表示します。
引数のエラーでは、使い方を標準エラー出力に表示します。
途中でエラーになった場合、それまでに計算した結果は出力済みです。
